# Menú digital — La Sazón de Lita

Proyecto independiente con el menú interactivo de La Sazón de Lita, Km 42 vía Cali–Dagua. Incluye fotos reales tomadas de los afiches compartidos, selección de platos, enlaces de pedido por WhatsApp y modo de edición local.

## Abrir

El punto de entrada es `index.html`. En GitHub Pages, publica desde la rama `main` y abre la carpeta `proyectos/menu-digital-la-sazon-de-lita/`. También puedes usar el sitio desplegado: https://la-sazon-de-lita.frajabar21.chatgpt.site

## Editar

Pulsa **Editar menú** para cambiar los datos y fotos de los productos. Los cambios de la interfaz se guardan en el almacenamiento local del navegador donde se editó el menú.

Las imágenes se incluyen en módulos JavaScript pequeños dentro de `assets/` para que el proyecto pueda servirse como archivos estáticos sin dependencias externas.
